# 美工约稿小票

选择菜单里的品项和规格，为各制品选择用途，填写委托信息和加项，再预览并下载 PNG 小票。起步价可以直接在本单改。常用价目表可编辑，抬头可上传透明 PNG 并添加署名。

## 计价规则

- 自用 ×1，商用 ×2，买断 ×3。默认可公开。不公开时用途倍率加 0.5，自用 ×1.5、商用 ×2.5、买断 ×3.5。
- 普通排期 ×1，3 天内 ×2，24 小时内 ×2.5。调整后的用途倍率与加急倍率相乘。
- 整张小票的商用和买断制品合并计算 set 门槛，折扣只应用于这些制品。未填同模组号的项目按数量计算。同模不同图填写相同组号，合计计 1 件。6 至 8 件九折，9 件起八折。
- 双闪 ¥8/面、烫金 ¥5/面、逆向 ¥12/面，按实际工艺面数选择。工艺与其他加项先并入小计，再计算倍率和折扣。买断可为本单勾选免工艺费及赠制品。
- 小票列出用途、应用的倍率、折扣和合计。填写整单备注后才显示备注。金额最终按分四舍五入。

报价、草稿和抬头保存在当前浏览器。新建小票或切换历史小票会保存当前草稿，可在「历史小票」继续编辑。每张小票保存自己的版头、署名和配色。

## 运行与发布

本地运行 `python3 -m http.server 8765`，打开 `http://localhost:8765/`。用 `node tests/pricing.test.mjs` 检查计价。

GitHub Pages 以 `main` 分支的根目录作为发布源。
