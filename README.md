# 美工约稿小票

选取常用项目，填写委托信息和加项，预览并下载 PNG 小票。首次使用时，打开「编辑常用报价」替换示例价，再在「小票抬头」上传自己的图案和填写署名。

## 计价

同模项目填同一组号。每组第一项的设计费按全价，其余项目的设计费按半价。工艺、改稿、衍生等加项按填写的整项费用计入。单项按分四舍五入，所有项目小计相加后再乘用途倍率。个人自用默认 ×1，商用 / 贩售默认 ×2，也可选择自定义倍率。

报价、草稿和抬头保存在当前浏览器。新建小票会清除本单内容，并保留常用报价和抬头。发送给客妹时可直接分享导出的 PNG。

## 运行与发布

本地运行 `python3 -m http.server 8765`，打开 `http://localhost:8765/`。用 `node tests/pricing.test.mjs` 检查计价。

GitHub Pages 以 `main` 分支的根目录作为发布源，无需构建。
